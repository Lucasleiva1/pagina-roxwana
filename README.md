# ROXWANA Web

Primera version visual funcional del ecommerce ROXWANA.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## Desarrollo

```bash
npm.cmd install
npm.cmd run dev
```

Abrir `http://127.0.0.1:3000`.

## Validacion

```bash
npm.cmd run lint
npm.cmd run build
npm.cmd audit --omit=dev
```

## Configuracion

Copiar `.env.example` a `.env.local` y completar el numero real de WhatsApp.
